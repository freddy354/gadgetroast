A program that writes one roast line about a gadget the writer uses every day to `/output/entry.txt`.

**My earbuds die at exactly 61% each, separately, like two coworkers who won't admit they're both quitting.**

## Why this line

It won a pairwise judge simulation (model glm-5.3-flash, the same family as the bounty judge) against 9 other candidates, judged with the exact published brief: roasts a daily gadget in a single line, actually funny, fresh angle, neatly worded, one person's specific gripe with a concrete detail. It beat the laptop-fan line in round 1, won the semifinals in both label orders, and took the final round-robin with 2.50 points (messaging-app "typing... then k" 2.00, alarm-app klaxon 1.50). The sting is specific — two earbuds dying at the same odd percentage, separately — not the generic "my battery is bad" complaint.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
